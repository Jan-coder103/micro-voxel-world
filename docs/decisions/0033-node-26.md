# Node.js 26 development runtime

Accepted 21 November 2026 at Jan's request after moving the laptop to Kubuntu.

Use Node.js 26.x for development. The package engine range, lockfile root and
`.nvmrc` agree; README and the development guide describe the current setup.
Historical Node 24 measurements and handoffs remain unchanged.

Node 26 removed `--experimental-transform-types`. The settlement and combat
benchmark scripts now use `node --import tsx` to retain parameter-property
support without changing simulation code. `tsx` is a development dependency;
the existing combat CLI regression exercises the new invocation. Other asset
CLIs continue to use native Node TypeScript stripping. Runtime browser bundles
and gameplay are unchanged.
